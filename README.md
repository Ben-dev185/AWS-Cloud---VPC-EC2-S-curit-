# AWS Cloud - VPC, EC2 & Sécurité

## Présentation

Ce projet vise à construire une infrastructure cloud sécurisée sur AWS en utilisant les principaux services d'infrastructure. L'objectif était de comprendre la conception réseau dans le cloud ainsi que les mécanismes de sécurité et de gestion des accès.

## Objectifs

- Concevoir une architecture réseau cloud
- Créer un VPC sécurisé
- Déployer une instance EC2 Linux
- Configurer IAM
- Mettre en place les Security Groups
- Gérer le stockage avec EBS

## Services AWS utilisés

- Amazon VPC
- Amazon EC2
- Amazon EBS
- IAM
- Security Groups
- Internet Gateway
- Route Tables

## Réalisations

### Architecture réseau

- Création d'un VPC
- Définition du CIDR 10.0.0.0/16
- Création de sous-réseaux publics et privés
- Configuration des tables de routage
- Mise en place de l'Internet Gateway

### Déploiement EC2

- Création d'une instance Linux
- Configuration des clés SSH
- Installation d'Apache2
- Accès distant sécurisé

### Sécurité

- Mise en œuvre du principe du moindre privilège
- Création de rôles IAM
- Configuration des Security Groups
- Restriction des accès SSH

### Stockage

- Création et attachement d'un volume EBS
- Gestion des snapshots
- Sauvegarde des données
